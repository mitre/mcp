Threat Actors:

  - BlackMatter: Originally associated with the BlackMatter Ransomware-as-a-Service (RaaS) operation, but variants are now used by other RaaS groups.

Malware:
  - Exmatter: A custom exfiltration tool used by ransomware operators to steal user files, databases, and compressed files. It uploads data to a preconfigured server via SFTP.  It also has anti-forensic capabilities and can use a WebDav client as a secondary exfiltration method.
  - Ryuk Infostealer: An exfiltration tool capable of programmatic identification and automatic exfiltration of data.
  - StealBit: An exfiltration tool capable of programmatic identification and automatic exfiltration of data, associated with the LockBit 2.0 operator.
  - Conti Ransomware: A ransomware group that a newer variant of Exmatter was observed being used with for exfiltration.

Tools:
  - Exmatter: Custom exfiltration tool that iterates through folders, prioritizes recently modified files, and excludes directories within 'C:\ProgramData\'. It uses SFTP to exfiltrate data, with options for WebDav failover and a SOCKS5 proxy.
  - PowerShell: Used by Exmatter to overwrite the file and delete itself after exfiltration, employing anti-forensic techniques.
  - ADFind: Tool used for network and Active Directory administration that can be abused for reconnaissance.
  - Advanced IP Scanner: Tool used for network scanning that can be abused for reconnaissance.
  - Windows Sysinternals suite: Legitimately signed binaries that can be used for malicious activities like credential dumping (Procdump) and malware/ransomware deployment (PsExec).
  - Themida: Anti-reverse engineering software protection utility used to protect the Exmatter executable.
