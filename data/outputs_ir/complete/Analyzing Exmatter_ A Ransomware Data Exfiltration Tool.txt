Threat Actors:
  - Originally associated with the BlackMatter Ransomware-as-a-Service (RaaS) operation, but variants are now used by other RaaS groups.

Malware:
  - A custom exfiltration tool used by ransomware operators to steal user files, databases, and compressed files. It uploads data to a preconfigured server via SFTP.  It also has anti-forensic capabilities and can use a WebDav client as a secondary exfiltration method.
  - An exfiltration tool capable of programmatic identification and automatic exfiltration of data.
  - An exfiltration tool capable of programmatic identification and automatic exfiltration of data, associated with the LockBit 2.0 operator.
  - A ransomware group that a newer variant of Exmatter was observed being used with for exfiltration.

Tools:
  - Custom exfiltration tool that iterates through folders, prioritizes recently modified files, and excludes directories within 'C:\ProgramData\'. It uses SFTP to exfiltrate data, with options for WebDav failover and a SOCKS5 proxy.
  - Used by Exmatter to overwrite the file and delete itself after exfiltration, employing anti-forensic techniques.
  - Tool used for network and Active Directory administration that can be abused for reconnaissance.
  - Tool used for network scanning that can be abused for reconnaissance.
  - Legitimately signed binaries that can be used for malicious activities like credential dumping (Procdump) and malware/ransomware deployment (PsExec).
  - Anti-reverse engineering software protection utility used to protect the Exmatter executable.
